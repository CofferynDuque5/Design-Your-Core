Los seis pilares

Cada pilar tiene un color para texto y etiquetas y otro, algo más vivo, para gráficos. Siempre aparecen en este orden y se acompañan de su nombre o icono, nunca del color solo.

Fundamentos

Color

El azul profundo es la acción principal. Salvia, arena y terracota acompañan, no compiten. La proporción indica el contraste con las tarjetas del tema activo; el texto necesita 4.5:1 como mínimo.

Fundamentos

Tipografía

Newsreader para titulares y momentos de reflexión; Figtree para la interfaz y la lectura. En la app móvil se cargan con expo-google-fonts.

Fundamentos

Espaciado y radios

Todo espacio es múltiplo de 4. Los radios son contenidos para mantener el tono editorial; el de píldora queda para etiquetas y chips.
